② Word Count Mapper — Step-by-Step Internal Logic
1
📥
Receive Input Line
Hadoop's TextInputFormat splits HDFS files into chunks. LineRecordReader feeds each line as a Text value to the mapper.
key: LongWritable (byte offset)
val: Text "Machine LEARNING is powerful"
2
🔡
Lowercase Conversion
The entire line is converted to lowercase so "Machine" and "machine" are counted as the same word.
line.toLowerCase()
"machine learning is powerful"
3
🧹
Strip Punctuation
All non-alphanumeric characters (except spaces) are removed using regex, leaving only clean words.
replaceAll("[^a-zA-Z0-9\s]", "")
"machine learning is powerful"
4
✂️
Tokenize (Split)
Split the cleaned line by one or more whitespace characters to produce an array of individual word tokens.
line.split("\\s+")
["machine","learning","is","powerful"]
5
📤
Emit Key-Value Pairs
For each non-empty token, emit the word as key and integer 1 as value into the MapReduce context.
context.write("machine", 1)
context.write("learning", 1)
context.write("is", 1)
context.write("powerful", 1)
6
⚙️
Reducer Aggregation
After Shuffle & Sort, reducer receives the same word with all its 1s. It sums them to get the total frequency across the entire corpus.
"machine" → [1,1,1,1,1]
sum = 5
output: "machine" → 5
③ Co-Occurrence Mapper — Detailed Logic with Distributed Cache
setup() — Distributed Cache Loading
The setup() method runs once per Mapper JVM before any records are processed. It loads top10.txt from the distributed cache into a HashSet for O(1) lookups.
// Called once before map() runs protected void setup(Context ctx) { URI[] cacheFiles = ctx.getCacheFiles(); // Find top10.txt in localized cache for (URI uri : cacheFiles) { if (fileName.equals("top10.txt")) { top10File = fileName; break; } } // Read words into HashSet BufferedReader reader = new BufferedReader( new FileReader(top10File)); while ((line = reader.readLine()) != null) { top10Words.add(parts[0]); // word only } }
map() — Adjacent Pair Generation
For each line, the mapper slides through adjacent word pairs. It only emits a pair if the first word is in the Top-10 set — reducing output dramatically.
// Runs for every input line public void map(Object key, Text value, Context ctx) { String[] words = line.split("\\s+"); for (int i = 0; i < words.length - 1; i++) { String word1 = words[i]; String word2 = words[i + 1]; // FILTER: only Top-10 first words if (!top10Words.contains(word1)) continue; // Emit adjacent pair pair.set(word1 + " " + word2); ctx.write(pair, ONE); // e.g. "the book" → 1 } }
Example — Input line:
"the book about machine learning"
Assuming "the" is in Top-10:
emit: "the book" → 1
skip: "book about" (book ∉ top10)
skip: "about machine" (about ∉ top10)
skip: "machine learning" (machine ∉ top10)
