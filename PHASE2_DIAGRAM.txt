║                          KEY DESIGN DECISIONS                                 ║
╚═══════════════════════════════════════════════════════════════════════════════╝

    Why MapReduce for Phase 1?                 Why Spark for Phase 2?
    ┌──────────────────────────┐               ┌──────────────────────────┐
    │ ✅ Disk-based processing │               │ ✅ In-memory iteration   │
    │ ✅ Fault-tolerant        │               │ ✅ 10-100x faster for ML │
    │ ✅ Scales to PB          │               │ ✅ Rich ML library       │
    │ ✅ One-pass aggregation  │               │ ✅ DataFrame API         │
    │ ❌ Slow for iteration    │               │ ❌ Memory-limited        │
    └──────────────────────────┘               └──────────────────────────┘

    Why Text Files as Bridge?
    ┌─────────────────────────────────────────────┐
    │ ✅ Universal - any tool can read           │
    │ ✅ Human-readable - easy debugging         │
    │ ✅ No schema lock-in                       │
    │ ✅ Versioned alongside code                │
    │ ✅ Works with Spark, Hive, Python, R, etc. │
    └─────────────────────────────────────────────┘
